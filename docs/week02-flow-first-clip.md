# 2주차 — 스킬 I: 카메라

실 수업 110분. 목표: 드론 무빙 3종(FPV 푸시인·오비트 각도 명시·로우앵글 틸트업)과 렌즈
어휘(14mm/85mm)를 6계층 프롬프트 순서 안에서 쓸 수 있게 한다. 스틸로 먼저 승인받고, 영상은
승인 후에만 만든다(수업 규칙 1: 스틸 먼저, 영상은 승인 후).

## 대면 / 숙제

- **대면 필수(110분)**: 따라잡기 15분(1주차 시작 조건 미달 학생) / 무빙 3종 시연·실패 패턴
  20분 / 학생 스틸 생성→강사 판정 45분 / 영상 1회 생성·비교 30분.
- **숙제(약 3시간, 생성 대기 제외)**: 무빙 2종 추가(스틸 승인은 자기채점표 6항) + 6계층
  프롬프트 5개 작성 + 크레딧 장부 기록.
  - Claude Code에게 붙여넣는 지시문: *"이 스틸 프롬프트를 6계층 순서(주제·
    시대 → 환경적 맥락 → 카메라 → 조명·날씨 → 질감·스타일 → 길이)로 다시 써 줘."*
  - 자기 확인: 자기채점표 6항(아래) 전부 체크.
- **다음 주 시작 조건**: 클립 5개 + 장부 기록.

## 타임라인

| 분 | 내용 |
| ---: | --- |
| 0~15 | 따라잡기(1주차 미완료 학생 1:1) |
| 15~35 | 무빙 3종 시연 + 실패 패턴(카메라 지시 누락 시 붕괴) |
| 35~80 | 학생 스틸 생성 → 강사 판정 |
| 80~110 | 영상 1회 생성·시연 스틸과 비교 |

## 체크리스트

1. **드론 무빙 3종 어휘 확인**
   - FPV 푸시인: `FPV drone push-in, low altitude, accelerating toward the {subject}`
   - 오비트(각도 명시): `slow 90-degree orbit around the {subject}, camera at 30-degree elevation`
   - 로우앵글 틸트업: `extreme low angle, slow tilt-up toward the {subject}`
   - 확인 방법: 세 문장 모두 "카메라가 무엇을 하는지"가 동사로 명시되어 있다(피사체 동사 없음).

2. **렌즈 어휘 추가**
   - 광각 `14mm ultra-wide` 또는 표준 `85mm` 중 장면에 맞는 것을 3계층(카메라)에 넣는다.
   - 확인 방법: 프롬프트 3계층에 렌즈값이 숫자+mm로 들어가 있다.

3. **6계층 순서로 스틸 프롬프트 작성**
   - 순서: 주제·시대 → 환경적 맥락 → 카메라(무빙+렌즈) → 조명·날씨 → 질감·스타일 → 길이.
   - 말미에 정적 피사체 절을 반드시 붙인다.
   - 확인 방법: 여섯 항목이 프롬프트 문장에서 이 순서로 나타난다.

4. **스틸 생성 → 강사 판정**
   - t2i로 스틸을 만들고 강사에게 보인다.
   - 확인 방법: 무빙 의도(푸시인/오비트/틸트업)가 정지 이미지의 구도에서도 읽힌다.

5. **영상 1회 생성·비교**
   - 승인된 스틸을 시작 프레임으로 i2v를 1회만 생성한다.
   - 확인 방법: 카메라만 움직이고 피사체는 고정되어 있다.

## 자기채점표 (숙제 제출용, 6항)

| # | 항목 | 통과 기준 |
| --- | --- | --- |
| 1 | 무빙 의도 | 의도한 무빙(푸시인/오비트/틸트업)이 영상에서 그대로 보인다 |
| 2 | 피사체 고정 | 건물·구조물이 흔들리거나 무너지지 않는다 |
| 3 | 6계층 순서 | 프롬프트가 순서대로 작성되어 있다 |
| 4 | 정적 피사체 절 | 프롬프트 말미에 절이 있다 |
| 5 | 렌즈 표기 | 카메라 계층에 mm 값이 있다 |
| 6 | 길이 표기 | 프롬프트 끝에 "8 seconds." 등 길이가 있다 |

## 흔한 오류 3개

1. **무빙 문장에 피사체 동사가 섞임**
   - 원인: "the building rises" 등 피사체를 움직이는 서술이 들어감.
   - 조치: 동사의 주어를 항상 카메라로 두고, 피사체는 "remains static"으로만 서술한다.

2. **Flow 우측 에이전트 패널이 composer를 가림**
   - 원인: 프로젝트를 새로 열면 우측에 에이전트 패널이 자동으로 도킹된다.
   - 조치: 패널의 X(닫기)를 한 번 눌러 닫는다. (강사 배포 자료)
     Recovery runbook 참조.

3. **렌즈 값 없이 카메라 계층을 씀**
   - 원인: "drone shot" 정도로만 쓰고 mm 값을 빠뜨림.
   - 조치: 14mm(광각) 또는 85mm(표준) 중 하나를 반드시 숫자로 넣는다.
