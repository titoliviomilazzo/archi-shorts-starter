# 1주차 — 환경: 설치·계정 연결 + Flow 첫 생성 + 스킬 0

실 수업 110분. 목표: 스타터 킷을 clone하고 `ep.py init`을 성공시킨 뒤, Flow에서 스킬 0(정적
피사체 절 유/무 비교)을 직접 보고 8초 클립 1개를 만들어 규격을 확인한다. 계정 3종(Google AI
Pro·GitHub·Claude Pro) 가입은 사전 안내 메일로 수업 전에 완료된 상태를 전제로 한다. 시간이
빡빡하다는 것은 강사 계획에 반영되어 있다 — 늦는 조는 6번(클론)까지만
끝내고 나머지는 과제로 넘긴다.

## 대면 / 숙제

- **대면 필수(110분)**: 오리엔테이션 10분 / 계정·설치 라이브 트러블슈팅 30분 / Flow 첫 t2i +
  스킬 0(정적 피사체 절 유/무) 비교 시연 35분 / i2v 생성 함께 진행 35분.
- **숙제(약 3시간, 생성 대기 제외)**: 클립 1개 재생성(다른 건물) + `ep.py init` 재확인 + 크레딧
  장부 1행 기록.
  - Claude Code에게 붙여넣는 지시문: *"방금 만든 프롬프트에서 건물만 다른 건물로 바꿔서
    스틸→영상을 다시 만들어줘. 정적 피사체 절은 그대로 유지해."*
  - 자기 확인: 절 있음/없음 결과를 나란히 재생해 건물이 고정되는지 스스로 비교한다.
- **다음 주 시작 조건**: 클립 1개 재생성 + 장부 1행. 못 맞춘 학생은 2주차 첫 15분 따라잡기
  블록에서 강사가 1:1로 본다.

## 체크리스트

1. **VS Code 설치 확인**
   - VS Code를 실행한다. 확인: 창이 뜨고 좌측에 탐색기 아이콘이 보인다. 없으면
     code.visualstudio.com에서 설치한다.

2. **Git 설치 확인**
   - 터미널에서 `git --version`. 확인: `git version 2.x.x` 출력. 안 되면 git-scm.com에서 설치.

3. **GitHub 로그인**
   - github.com에 로그인. 확인: 우측 상단에 본인 프로필 아이콘.

4. **Claude Code 설치·로그인**
   - 공식 설치 문서의 현재 명령을 따른다: https://docs.anthropic.com/en/docs/claude-code
     (명령을 이 실습지에 고정 문자열로 적지 않는다 — 버전마다 바뀐다)
   - 터미널에서 `claude` 실행. 확인: 브라우저 인증 후 대화 입력 프롬프트가 보인다.

5. **스타터 킷 clone — Template repository → VS Code GUI**
   - 5-1. 브라우저에서 https://github.com/titoliviomilazzo/archi-shorts-starter을 연다. **"Use this template"** → "Create a new
     repository". 확인: 본인 소유 저장소(`<본인계정>/<저장소이름>`)로 이동한다.
   - 5-2. **"Code"** 버튼으로 저장소 URL을 복사한다. 확인: 복사 완료 체크 아이콘.
   - 5-3. VS Code 명령 팔레트(Ctrl+Shift+P) → **「Git: Clone」**. URL을 붙여넣고 로컬 폴더를
     선택한다. 확인: clone 진행률 알림 → "Open" 팝업에서 Open.
   - 5-4. 좌측 탐색기에서 `scripts/`·`templates/` 폴더 확인. git 명령어를 타이핑하지 않았다.

6. **폴더 구조 설명 받기 + `ep.py init`**
   - 클론한 폴더에서 `claude` 실행 → "이 폴더 구조를 설명해줘". 확인: `scripts/`·`templates/`·
     `episodes/` 역할 설명이 나온다.
   - `python scripts/ep.py init --episode <ep>` 실행(`<ep>`는 강사가 지정). 확인:
     `episodes/<ep>/` 폴더 생성, 오류 없이 종료.

7. **크레딧 장부 첫 행**
   - Flow 로그인 후 화면 상단 크레딧 잔액을 확인해 `credit-ledger-template.md` 1주차 행
     "생성 전 잔액"에 기록한다.

8. **스킬 0 — 정적 피사체 절 유/무 비교 (t2i)**
   - 같은 프롬프트를 정적 피사체 절 유/무로 각 1장씩 t2i 생성한다. 절 원문:
     `The architecture remains perfectly static, solid, and undistorted; only the camera moves.`
     (강사 배포 스킬 카드 §카메라 어휘). 이미지는 0크레딧.
   - 확인: 절이 없으면 건물 형태가 흔들리거나 무너지고, 있으면 카메라만 움직이고 건물이
     고정된 것을 눈으로 비교한다.

9. **i2v 8초 1개 생성·다운로드**
   - 통과한 이미지를 시작 프레임으로 i2v 8초 영상을 생성하고 로컬에 다운로드한다. 확인: 8초
     근처 길이의 `.mp4` 파일이 생긴다.

10. **ffmpeg 설치 + `ffprobe` 규격 확인**
    - Claude Code에 "ffmpeg를 설치해줘" 요청 → `ffmpeg -version` 확인.
    - `ffprobe <파일명>` 실행. 확인: 해상도(예: 1280x720)와 `Duration:` 값이 보인다.

11. **크레딧 재기록·단가 계산**
    - Flow 잔액을 다시 확인해 장부 "생성 후 잔액"에 기록하고, (전−후)를 "소모"에 적는다. 이
      값이 8초 i2v 1개의 실측 단가다 — 이후 주차 킷 수 설계에 쓴다.

## 흔한 오류 3개

1. **Windows PATH 미반영**
   - 원인: 설치 직후 새 명령이 현재 터미널 세션에 반영되지 않음.
   - 조치: 터미널을 완전히 닫고 새로 연다.

2. **GitHub 로그인 브라우저 미열림**
   - 원인: 방화벽·보안 소프트웨어가 자동 브라우저 실행을 차단.
   - 조치: 터미널에 표시된 인증 URL을 수동으로 복사해 브라우저에 붙여넣는다.

3. **Flow 우측 에이전트 패널이 composer를 가림**
   - 원인: 프로젝트를 새로 열면 우측에 에이전트 패널이 자동으로 도킹된다.
   - 조치: 패널의 X(닫기)를 한 번 눌러 닫는다. (강사 배포 자료)
     Recovery runbook 참조.
